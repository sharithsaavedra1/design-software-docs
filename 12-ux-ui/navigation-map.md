# Mapa de Navegación del Sistema

El flujo general para un rol logueado como `Coordinador Académico`.

1. `[ Login ]`
2. `[ Dashboard Principal ]` (Resumen de cuántas Horas le faltan por programar este trimestre).
   - `[ Gestión de Maestros ]` (Carpeta anidada)
     - -> Lista Instructores del Centro.
     - -> Lista Ambientes Físicos.
   - `[ Bandeja de Programación de Horario ]` (El Core del sistema)
     - -> Vista Semanal Grilla.
     - -> Modal (Popup) de resolución de conflictos manual.
   - `[ Reportes ]` -> Visor global (Read Only) y descarga.
