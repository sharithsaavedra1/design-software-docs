# document-api

> Estado: 🔴 Pendiente | Última actualización: 2026-06-17

## Tipo de componente

`-api` — REST API sincrónica

## Responsabilidad

Gestiona documentos y sus versiones. Permite cargar, consultar, versionar y obtener URLs de descarga. No genera documentos directamente; la generación la hace `pdf-renderer-worker`.
