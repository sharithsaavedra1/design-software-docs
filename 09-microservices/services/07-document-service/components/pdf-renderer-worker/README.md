# pdf-renderer-worker

> Estado: 🔴 Pendiente | Última actualización: 2026-06-17

## Tipo de componente

`-worker` — Consumidor de cola

## Responsabilidad

Genera archivos PDF y Excel a partir de plantillas y datos recibidos por cola. Guarda el resultado en object storage y actualiza el estado del documento en `document_db`.
