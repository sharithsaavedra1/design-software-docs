# actors-api

> Estado: 🔴 Pendiente | Última actualización: 2026-06-17

## Tipo de componente

`-api` — REST API sincrónica

## Responsabilidad

Gestiona instructores, aprendices, empresas y sus relaciones. Es consultada por `scheduling-service` para validar la disponibilidad e idoneidad de instructores al crear sesiones de clase.
