# schedules-api

> Estado: 🔴 Pendiente | Última actualización: 2026-06-17

## Tipo de componente

`-api` — REST API sincrónica

## Responsabilidad

Expone las operaciones CRUD de horarios y sesiones, y dispara el `scheduling-engine-workflow` para la creación asistida de horarios. Es la interfaz del usuario final con el motor de horarios.
