# notification-worker

> Estado: 🔴 Pendiente | Última actualización: 2026-06-17

## Tipo de componente

`-worker` — Consumidor de cola (despacho de notificaciones salientes)

## Responsabilidad

Despacha notificaciones a los destinatarios configurados. Soporta múltiples canales (email, push, SMS). Registra el resultado del envío en `notificacion_enviada`.
