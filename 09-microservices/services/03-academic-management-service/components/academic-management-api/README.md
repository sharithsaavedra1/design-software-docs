# academic-management-api

> Estado: 🔴 Pendiente | Última actualización: 2026-06-17

## Tipo de componente

`-api` — REST API sincrónica

## Responsabilidad

CRUD de la estructura curricular (programas, competencias, RAPs) y de los grupos de formación (fichas, ofertas). Es el proveedor de datos para `scheduling-service` y `actors-service`.
